# Claim Boundary

This project validates ads-science capabilities using public datasets or synthetic fallback data and connects modules through a synthetic integration layer.

It does not use:

- proprietary Amazon Ads data
- real advertiser data
- real customer data
- production traffic
- production deployment
- online A/B testing on live users

All results are local-runnable, public-data-compatible, and production-style portfolio evidence only.

Recommended resume wording:

> Built a local-runnable, public-data-compatible ads applied-science framework...

Do not write:

> Built a production Amazon Ads system.
> Deployed models on Amazon Ads traffic.
> Used Amazon customer or advertiser data.
