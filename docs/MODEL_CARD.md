# Model Card

## Model families

- Logistic Regression CTR baseline
- Gradient Boosting CTR baseline
- Optional PyTorch embedding MLP
- Empirical-Bayes calibration
- Mechanism-informed residual correction
- BM25/TF-IDF relevance baseline
- Candidate expansion and reranking
- T-learner uplift model
- IPS/SNIPS/Doubly Robust OPE estimators

## Intended use

Offline evaluation, applied science portfolio demonstration, and release-decision workflow simulation.

## Not intended use

Production advertising traffic, real customer targeting, or real advertiser budget allocation.
